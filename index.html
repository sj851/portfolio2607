주제 01 · 피부체형 센터

상품 믹스 재편으로 ROAS 6.6배 — "더 싸게"가 아니라 "더 잘 팔리는 곳에"

예산 전략
Situation 2025년 4월부터 피부체형 센터를 담당하게 됐을 때, 저효율 상품에 예산이 분산돼 ROAS가 정체돼 있었습니다.
Problem 획득DB단가(CPA)보다 예약 전환이 낮은 상품 구조가 근본 원인이었지만, 운영은 CPA 최적화에만 집중돼 있었습니다.
Analysis 상품별 퍼널(광고비→DB수집→예약→내원→매출)을 분해해보니, CPA가 싸도 예약 전환이 낮은 저효율 상품에 예산의 상당 부분이 묶여 있다는 것을 확인했습니다.
Action 고효율 상품을 분류해 저효율 상품 예산을 고전환 상품(가격소구 라인업)으로 재배분하고, 메타 외 고예약률 채널(구글·당근)을 함께 확장했습니다.
Result CPA는 거의 그대로인데 안착기 ROAS 6.6배를 달성했고, 고효율(ROAS≥2.5) 상품 예산 비중은 13%→59%로 늘었습니다.
Lesson ROAS 개선은 CPA 최적화만으로는 한계가 있고, 어떤 상품에 예산을 쓰느냐가 결과를 갈랐습니다.

입사 직전 주력 상품 판매 중단 이슈로 광고 집행이 급격히 위축된 상태였습니다. 입사 후 집행을 재가동하며 규모를 키우는 과정에서 CPA가 일시 상승(정상적 구간)했고, 7월부터 상품 가격 최적화 및 예산 재배분 효과가 나타나며 반전, 10~12월 ROAS 6.6배로 정점을 찍었습니다. 확장기에도 CPA는 2024년 이하로 유지됐습니다.

실행 상세
  1. 상품별 퍼널 분해 — 광고비→DB수집→예약→내원→매출 단계마다 효율 매핑
  2. 효율 매트릭스 — ROAS·예약률·내원율 기준으로 상품 분류, 유지/확대/정리 판단
  3. 단계적 예산 이동 — 저효율 상품 예산 축소, 고효율 상품으로 단계적 확대
  4. 채널 다변화 — 메타(볼륨·저단가) + 구글·당근(예약률 46~58%) 역할 분담 운영
  5. 가격 A/B 테스트 — 동일 상품 가격대별 ROAS·내원율 비교, 최적 가격 라인 검증
소재 예시

주제 02 · 롱래스팅 센터

롱래스팅 센터 재운영, 소재 컨셉 전환으로 CPA −37%·매출 +636%

소재 전략
Situation 운영이 종료됐던 롱래스팅 센터의 광고 운영을 맡아, 재운영 과정에서 광고 성과 개선을 담당했습니다.
Problem 광고비를 키울수록 소재가 빨리 피로해져 CPA가 오르는 문제가 반복될 것으로 예상됐고, 단순 리터치로 재투입해도 효과가 오래가지 못하는 패턴이었습니다.
Analysis 운영 기간 동안 진행한 소재 교체 사례 32건을 정리·분석한 결과, 포맷·소구점·모델이라는 축 자체를 바꿔야 같은 상품에서도 CPA가 회복된다는 것을 확인했습니다.
Action 채널별 CPA·노출빈도를 상시 모니터링해 소재 피로 시점을 포착하고, 그때마다 포맷(배너→브이로그형)·소구점(효과강조→팩트체크 리뷰)·모델을 다른 축으로 바꾼 신규 소재를 기획·제작했습니다.
Result 32건 중 22건(69%)에서 CPA가 개선됐고(평균 37% 감소, 최대 78% 감소), 재운영 직후 CPA는 23% 감소했으며, 확장기(광고비 ×3.5)에도 CPA 상승폭을 8% 이내로 유지했습니다. 광고기여매출은 월평균 636% 증가했습니다.
Lesson 소재 교체의 핵심은 속도가 아니라, 포맷·소구점·모델이라는 다른 축으로 바꾸는 것이었습니다.

실행 상세
  1. 채널별 CPA·노출빈도 모니터링으로 소재 피로 시점 포착
  2. 피로 신호 포착 시, 포맷(배너→브이로그형 영상)·소구점(효과강조→팩트체크 리뷰)·모델을 다른 축으로 바꾼 신규 소재 즉시 기획·제작
  3. 신규 소재 투입 후 초기 3주/안정화 구간 성과 비교, 효과적인 컨셉 축을 패턴으로 축적
  4. 제작 프로세스 개선 — 여러 편집 툴을 프리미어프로 기반으로 통합해 제작 과정을 단순화했고, 영상 1편 제작 기간도 5일→3일로 줄었습니다
  5. 신규 모수 확보(맞춤타겟 제외)로 광고 초반 단가 상승 방지, 고효율 매체 비중 확대 병행

주제 A · 페이스북 ROAS 캠페인

위기의 ROAS를 역대 최고로 — 객단가 재설계로 매출 ×3

상품 전략
Situation 광고대행사 위탁 운영 기간 ROAS가 110%까지 떨어진 시점에 직접운영으로 복귀했습니다.
Problem 페이스북은 전환단가가 가장 낮았지만 ROAS는 타 매체 절반 수준이었고, 매출 지표를 분해하자 객단가가 타 매체 대비 50% 수준이라는 게 근본 원인으로 드러났습니다.
Analysis ROAS 개선은 광고비 축소 또는 매출 상승 두 방향이 있었는데, 성장 중인 병원 상황을 고려해 광고비는 유지하면서 매출 상승으로 끌어올리는 방향을 선택했습니다.
Action 내원율 높은 시술을 중저가 패키지 상품으로 기획하고, 타겟 연령을 20대에서 20대 후반~30대로 확대했으며, 가성비를 강조한 배너로 전면 리뉴얼했습니다.
Result 4개월 만에 ROAS 110%→290%(역대 최고, 목표 250% 초과), 객단가 30%+ 향상, 매출은 3배로 늘었습니다. 동일 전략을 GFA에 적용해 ROAS 500%도 추가로 달성했습니다.
Lesson ROAS 개선은 운영 기술만으로는 한계가 있고, 어떤 상품을 누구에게 어떻게 패키징해서 보여줄지를 함께 설계해야 했습니다.

주제 B · 페이스북 예약률 캠페인

광고유형 전환 + CS 인터뷰 기반 배너로 전환단가 −35%

Situation 콜성과 데이터를 매체별로 재가공해 분석하던 중 페이스북 예약률(18%)이 유독 낮다는 것을 발견해, 페이스북 담당자로 추가 배정됐습니다.
Problem 부재율 60%+, 가격만 묻는 콜, 시술을 수술로 오인하는 문의가 많았고, 전환단가도 높아 효율이 이중으로 낮은 상황이었습니다.
Analysis 트래픽광고로 바꾸면 예약률은 개선되지만 전환단가가 오르는 게 고질적 문제였고, 광고유형과 배너를 함께 재설계해야 두 문제를 동시에 풀 수 있다고 판단했습니다.
Action 잠재광고를 트래픽광고로 전환하고, CS팀 인터뷰로 파악한 고객 질문을 배너에 반영(시술효과·나이는 노출, 가격은 미표기)했으며, 타겟 세분화와 노출 빈도 관리를 병행했습니다.
Result 랜딩페이지 조회율 25배, 조회당 비용 −95%, 전환단가 −35%, 전체 예약률 +5%p를 기록했습니다.
Lesson 광고유형과 배너 콘텐츠는 세트로 바꿔야 효과가 나고, 유형만 바꾸면 개선이 제한적이었습니다.
실행 상세
  1. 콜성과 데이터 재가공 — 개인 콜성과 데이터를 광고매체별로 통합해 예약률 문제 발견
  2. 트래픽광고 전용 배너 기획 — CPM 과금방식에 맞춰 클릭률 최대화 목표, 정보량 10줄→2~3줄로 압축
  3. 정보 노출 전략 — CS팀 인터뷰로 고객 최다 질문 파악: 시술효과(2위)는 노출, 가격(1위)은 미표기로 궁금증 유발
  4. 타겟 세분화 — 이전 광고 참여 고객 데이터 기반 맞춤·유사 타겟 설정
  5. 캠페인 빈도 관리 — 1인당 노출 빈도·첫 노출 비율 데이터로 광고 피로도 관리
