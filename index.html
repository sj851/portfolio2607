About

메디빌더(오블리브앤파트너스 BU)에서 병원 MSO 데이터마케팅팀으로 메타·구글·틱톡·당근 광고를 운영하고 있고, 이전에는 더블어스(닥터홈즈의원)에서 3년 4개월간 피부과 인하우스 마케터로 일했습니다. 두 환경을 합쳐 5년 이상 광고 운영과 소재 기획·제작을 병행해왔습니다.

매체 데이터에서 이상 신호나 정체 구간을 발견하면 원인을 확인하고 개선 방향을 판단하며, 판단이 서면 소재·상품·예산 구조에 직접 반영해 수치로 결과를 확인하는 방식으로 일합니다. 아래 프로젝트들은 그 과정을 회사·센터별로 정리한 기록입니다.

주제 01 · 롱래스팅 센터(송도점)

종료됐던 센터 재운영 → 소재 컨셉 전환·스케일로 매출 +677%

소재 전략
Challenge 운영이 종료됐던 롱래스팅 송도점의 광고 운영을 맡아, 재운영 과정에서 광고 성과 개선을 담당했습니다. 광고비를 키울수록 소재가 빨리 피로해져 CPA가 오르는 문제가 반복될 것으로 예상됐고, 단순 리터치로 재투입해도 효과가 오래가지 못하는 패턴이었습니다.
Insight 운영 기간 동안 진행한 소재 교체 사례 32건을 정리·분석한 결과, 포맷·소구점·모델이라는 축 자체를 바꿔야 같은 상품에서도 CPA가 회복된다는 것을 확인했습니다.
Action 채널별 CPA·노출빈도를 상시 모니터링해 소재 피로 시점을 포착하고, 그때마다 포맷(배너→브이로그형)·소구점(효과강조→팩트체크 리뷰)·모델을 다른 축으로 바꾼 신규 소재를 기획·제작했습니다.
Result 소재 교체 32건 중 22건(69%)에서 CPA가 개선됐고(평균 37% 감소, 최대 78% 감소), 재운영 직후 CPA는 22% 감소했습니다. 확장기(광고비 4.2배)에도 CPA를 −3%로, 재운영 전체로도 −8%로 오히려 낮게 유지했습니다. 광고기여매출은 +677% 성장 — 예산 4배 × 효율(ROAS) 2배 = 매출 약 8배 구조입니다.

매출 +677%는 광고비 ×4.2(스케일)와 ROAS ×1.84(효율)가 곱해진 결과로, 성장액의 스케일·효율 기여가 약 반반입니다. 물량을 4배 키우면 보통 단가가 오르는데, 소재 교체 사이클로 CPA를 오히려 낮게 유지한 것이 스케일을 가능케 했습니다.

실행 상세
  1. 채널별 CPA·노출빈도 모니터링으로 소재 피로 시점 포착
  2. 피로 신호 포착 시, 포맷(배너→브이로그형 영상)·소구점(효과강조→팩트체크 리뷰)·모델을 다른 축으로 바꾼 신규 소재 즉시 기획·제작
  3. 신규 소재 투입 후 초기 3주/안정화 구간 성과 비교, 효과적인 컨셉 축을 패턴으로 축적
  4. 제작 프로세스 개선 — 여러 편집 툴을 프리미어프로 기반으로 통합해 제작 과정을 단순화했고, 영상 1편 제작 기간도 5일→3일로 줄었습니다
  5. 신규 모수 확보(맞춤타겟 제외)로 광고 초반 단가 상승 방지, 고효율 매체 비중 확대 병행
소재 예시

롱래스팅 송도점 재운영 후 제작한 눈썹문신 광고 영상입니다. 기존 소재가 피로해진 시점에 포맷과 소구점을 다른 축으로 바꿔 CPA를 회복시킨 컨셉 전환 소재입니다.

주제 02 · 롱래스팅 센터(종로점)

신규 지점 런칭 → 4개월 만에 주간매출 1억 달성(ROAS 5.0) — 검증된 플레이북 이식

신규 지점
Challenge 2026년 5월 신규 오픈한 종로점은 전환 프로세스가 검증되지 않은 상태였습니다. 물량을 빠르게 키우면서도 예약·매출 전환을 함께 끌어올려야 했습니다.
Action 송도점에서 검증한 플레이북(소재 컨셉 전환·채널 믹스)을 이식하고, 초기 병목이던 리드→예약 전환을 개선했습니다. 신규 지점 특성(저경쟁·신규 모수)을 살려 물량을 공격적으로 확대했습니다.
Result 오픈 4개월 만에 월 광고기여매출 0 → 290M, ROAS 3.7 → 5.0(송도급 도달). 최근 주매출은 100M을 돌파해 월 런레이트 약 400M 수준이며, 초기 병목이던 예약률을 27% → 47%로 끌어올렸습니다.

실행 상세
  1. 송도 플레이북 이식 — 소재 컨셉 전환(포맷·소구점·모델)·채널 믹스를 신규 지점에 적용
  2. 공격적 물량 확대 — 신규 저경쟁 모수를 활용해 주간 획득DB를 빠르게 스케일
  3. 전환 병목 개선 — 초기 예약률(27%)을 가격 명시 소재·채널 믹스로 47%까지 개선
  4. 주간 단위 런레이트 모니터링으로 급증 구간 대응
레슨런

검증된 운영 방식은 신규 지점에 이식했을 때 빠르게 재현됐고, 남은 과제는 '획득'이 아니라 '전환(예약률)'이라는 점이 데이터로 분명했습니다.

주제 03 · 피부체형 센터

상품 믹스 재편으로 ROAS 6.6배 — "더 싸게"가 아니라 "더 잘 팔리는 곳에"

예산 전략
Challenge 2025년 4월부터 피부체형 센터를 담당하게 됐을 때, 저효율 상품에 예산이 분산돼 ROAS가 정체돼 있었습니다. 운영은 획득DB단가(CPA) 최적화에만 집중돼 있었지만 좀처럼 개선되지 않는 상황이었습니다.
Insight 상품별 퍼널(광고비→DB수집→예약→내원→매출)을 분해해보니, CPA보다 예약 전환이 낮은 상품 구조가 근본 원인이었습니다. CPA가 싸도 예약 전환이 낮은 저효율 상품에 예산의 상당 부분이 묶여 있었던 겁니다. 예산을 저효율 상품에서 고효율 상품 중심으로 다시 배분해야 한다고 판단했습니다.
Action 고효율 상품을 분류해 저효율 상품 예산을 고전환 상품(가격소구 라인업)으로 재배분하고, 메타 외 고예약률 채널(구글·당근)을 함께 확장했습니다.
Result CPA는 거의 그대로인데 안착기 ROAS 6.6배를 달성했고, 고효율(ROAS≥2.5) 상품 예산 비중은 13%→59%로 늘었습니다.

실행 상세
  1. 상품별 퍼널 분해 — 광고비→DB수집→예약→내원→매출 단계마다 효율 매핑
  2. 효율 매트릭스 — ROAS·예약률·내원율 기준으로 상품 분류, 유지/확대/정리 판단
  3. 단계적 예산 이동 — 저효율 상품 예산 축소, 고효율 상품으로 단계적 확대
  4. 채널 다변화 — 메타(볼륨·저단가) + 구글·당근(예약률 46~58%) 역할 분담 운영
  5. 가격 A/B 테스트 — 동일 상품 가격대별 ROAS·내원율 비교, 최적 가격 라인 검증
소재 예시

피부체형 센터 주력 상품 소재입니다. 올타이트는 가격소구 중심, 올리디아는 시술 효과 중심, 색소지우개는 저단가 신규 상품 소구로 각 상품 특성에 맞게 기획했습니다.

Challenge 광고대행사 위탁 운영 기간 ROAS가 110%까지 떨어진 시점에 직접운영으로 복귀했습니다. 페이스북은 전환단가가 가장 낮았지만 ROAS는 타 매체 절반 수준이었고, 매출 지표를 분해하자 객단가가 타 매체 대비 50% 수준이라는 게 근본 원인으로 드러났습니다.
Insight ROAS 개선은 광고비 축소 또는 매출 상승 두 방향이 있었는데, 성장 중인 병원 상황을 고려해 광고비는 유지하면서 매출 상승으로 끌어올리는 방향을 선택했습니다.
Action 내원율 높은 시술을 중저가 패키지 상품으로 기획하고, 타겟 연령을 20대에서 20대 후반~30대로 확대했으며, 가성비를 강조한 배너로 전면 리뉴얼했습니다.
Result 4개월 만에 ROAS 110%→290%(역대 최고, 목표 250% 초과), 객단가 30%+ 향상, 매출은 3배로 늘었습니다. 동일 전략을 GFA에 적용해 ROAS 500%도 추가로 달성했습니다.

실행 상세
  1. 매출 지표 분해 — 객단가에서 페이스북이 타 매체 50% 수준이라는 문제 발견
  2. 광고상품 재설계 — 내원율 높은 다이어트 시술을 중저가 패키지로 묶어 기획
  3. 타겟 확대 — 구매력을 고려해 메인 타겟을 20대에서 20대 후반~30대로 상향
  4. 배너 리뉴얼 — 가성비 혜택 강조, 소재 전면 교체
  5. ROAS 중심 운영 — 광고지표 대신 매출지표(ROAS) 중심으로 캠페인 목적·예산 재편

레슨런

ROAS 개선은 운영 기술만으로는 한계가 있고, 어떤 상품을 누구에게 어떻게 패키징해서 보여줄지를 함께 설계해야 했습니다.

주제 B · 페이스북 예약률 캠페인

광고유형 전환 + CS 인터뷰 기반 배너로 전환단가 −35%

Challenge 콜성과 데이터를 매체별로 재가공해 분석하던 중 페이스북 예약률(18%)이 유독 낮다는 것을 발견해, 페이스북 담당자로 추가 배정됐습니다. 부재율 60%+, 가격만 묻는 콜, 시술을 수술로 오인하는 문의가 많았고, 전환단가도 높아 효율이 이중으로 낮은 상황이었습니다.
Insight 트래픽광고로 바꾸면 예약률은 개선되지만 전환단가가 오르는 게 고질적 문제였고, 광고유형과 배너를 함께 재설계해야 두 문제를 동시에 풀 수 있다고 판단했습니다.
Action 잠재광고를 트래픽광고로 전환하고, CS팀 인터뷰로 파악한 고객 질문을 배너에 반영(시술효과·나이는 노출, 가격은 미표기)했으며, 타겟 세분화와 노출 빈도 관리를 병행했습니다.
Result 랜딩페이지 조회율 25배, 조회당 비용 −95%, 전환단가 −35%, 전체 예약률 +5%p를 기록했습니다.
실행 상세
  1. 콜성과 데이터 재가공 — 개인 콜성과 데이터를 광고매체별로 통합해 예약률 문제 발견
  2. 트래픽광고 전용 배너 기획 — CPM 과금방식에 맞춰 클릭률 최대화 목표, 정보량 10줄→2~3줄로 압축
  3. 정보 노출 전략 — CS팀 인터뷰로 고객 최다 질문 파악: 시술효과(2위)는 노출, 가격(1위)은 미표기로 궁금증 유발
  4. 타겟 세분화 — 이전 광고 참여 고객 데이터 기반 맞춤·유사 타겟 설정
  5. 캠페인 빈도 관리 — 1인당 노출 빈도·첫 노출 비율 데이터로 광고 피로도 관리
소재 예시

같은 상품이지만 광고 유형에 따라 소재를 완전히 다르게 기획했습니다. 잠재광고는 가격 표기·즉시 신청 유도, 트래픽광고 영상은 가격 미표기·나이 표기·호기심으로 클릭 유도.
